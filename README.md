# Java Socket Chat Application

## Introduction
This is a simple chat application built using Java Socket.  
The program allows multiple clients to connect to a server and send messages in real time.

## Technologies
- Java
- Socket Programming
- NetBeans IDE

## Features
- Client - Server chat
- Send and receive messages
- Simple user interface

## Project Structure
src/chat
- chat_client.java
- chat_server.java
- ServerSocket.java

## How to Run
1. Open the project in NetBeans
2. Run the server first
3. Run the client
4. Start chatting
